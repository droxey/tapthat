# TapThat

NFC enamel beads for lifestyle events — cruises, resorts, pineapple weekends. Tap a disc, leave a moment, follow the bead after it leaves your hand. Inspired by [Soulstone](https://soulstone.io); this is a demo clone with no real payments.

## Live

https://tapthat-nine.vercel.app

## Quickstart

```bash
npm install
npm run dev          # app on port 8080
npm run build
npm test
npm run typecheck
```

## Demo limits

Auth is off. Cart, orders, newsletter, and taps live in `localStorage`. Physical discs would open a magic link at `/t/<CODE>` (try `/t/TT-FANS-004`).
